**Web applications · Backend systems · Machine learning**

[GitHub ↗](https://github.com/TymofiiZuren) &nbsp; / &nbsp; [LinkedIn ↗](https://www.linkedin.com/in/tymofii-mazurenko-338111371/)

## 01 / About

I'm **Tymofii**. I build web applications and backend systems, and explore machine learning through hands-on projects. My work connects practical problems with software: property discovery, consultation workflows, transaction data, and sentiment analysis.

**Selected interests** &nbsp; OpenHaus · Go data processing · SignalLab

<br />

## 02 / Selected work

### [OpenHaus ↗](https://github.com/TymofiiZuren/openhaus)

Property discovery across Ireland, with interactive maps and 360° tours.

`TypeScript` · `React` · `Go` · `PostGIS`

### [Hospital Consultation System ↗](https://github.com/TymofiiZuren/Hospital-Consultation-System)

A Java desktop GUI modelling hospital consultation workflows and basic interactions.

`Java` · `Desktop GUI`

### [Dataset Processor ↗](https://github.com/TymofiiZuren/dataset-processor)

Transaction processing with CSV validation and verifiable output manifests.

`Go` · `Data processing`

### [SignalLab ↗](https://github.com/TymofiiZuren/signallab)

A local learning app for sentiment models and synthetic-data experiments.

`Python` · `Streamlit` · `Machine learning`
